# React Student Management System

A UI-based Student Management System developed using React and JSX.

## Technologies

- React
- JSX
- JavaScript
- CSS
- Vite

## Features

- Home page
- Student registration form
- Form validation
- Student dashboard
- Registered student information
- Logout
- Responsive UI

## Run the project

Open a terminal inside this folder and run:

```bash
npm install
npm run dev
```

Then open the URL shown by Vite, normally:

```text
http://localhost:5173
```
